Öffne **Kantenquader.r3dp**, markiere den Quader und wähle **Kante in 3D wählen …**. Fahre von einer sichtbaren Fläche an ihren Rand. Ein Klick auf die markierte Linie bindet die Kante. Stelle Anfangsmaß, Endmaß und Facettenzahl ein und klicke auf **Parameter übernehmen**. Eine Facette erzeugt eine Fase. F1 öffnet die passende deutsche Offline-Hilfe.

Die direkte Auswahl gilt für den obersten Kantenbearbeitungsschritt. Innere Dreiecksdiagonalen sind von der Auswahl ausgenommen. Die bestehenden Grenzen der netzbasierten Kantenbearbeitung bleiben bestehen. Eine Ergebnisvorschau vor dem Übernehmen ist der nächste geplante Schritt.

Das ZIP enthält den Quellstand, Beispiele und die Programme für Windows und Linux x64. Unter Windows das Archiv entpacken und die EXE oder das Setup in `dist` starten.
Linux-Fensterabnahme mit Kanten- und Flächenklick, Speichern, Rückgängig und Wiederholen bestanden. Windows-Server-Abnahme bestanden. Die portable EXE öffnete und speicherte die Keilschale samt Flächenbezug. [Prüfprotokoll](https://github.com/ubi-psifu/rust-3d-print-studio/actions/runs/45085193850)
