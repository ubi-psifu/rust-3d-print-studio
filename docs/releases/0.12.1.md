Der Windows-Installer registriert Rust 3D Print Studio im Benutzerprofil für „Öffnen mit“ bei R3DP-Projekten. Eine vorhandene Standardanwendung bleibt erhalten. Pfade mit Leerzeichen werden als einzelnes Argument übergeben.

Die Versionsanzeige unter „Installierte Apps“ übernimmt die Paketversion aus Cargo.toml. Beim bisherigen Installer 0.12.0 stand dort irrtümlich 0.10.0.

Das ZIP enthält den Quellcode, die deutsche Anleitung, Beispiele, das Linux-x64-Programm sowie portable Windows-x64-EXE und Setup. Unter Linux bestanden 62 Tests, Formatierung, Workspace-Check, Clippy und Release-Build. Die Abnahme auf einem Windows-11-Arbeitsplatz steht aus.
